Quorance CSM Brain — Biological Fidelity Audit

Grounded in source read 2026-10-10: src/quorance/csm_brain.py, biological_cell.py, population.py, inhibitory.py, dendrite.py, runtime.py (arbiter). The question: does the code, forced to run, behave like a neuron / nervous system / brain?

Headline. The running CSM brain exercises ~5 mechanisms: a point-neuron integrate-and-fire (Neuron.decide), a per-platform Sensor (dendrites-of-the-afferent-nerve), Population lateral inhibition (cerebellum / basal ganglia), ReviewVerifier (brainstem), and a plain boolean human_approved gate (amygdala). 15 of the 20 proven "tested parts" are NOT wired into this runtime. Several mechanisms the brain DOES use are simplified in ways the code itself files as scaffolding (declared, not biology). The hero-cell diagram showing "ALL 20 TESTED PARTS" is accurate as a portfolio catalog of parts proven across all steps — but it overstates what this brain runs.

2 · Mechanism-by-mechanism — what the code does vs a real neuron

MechanismWhat the code doesWhat a real neuron doesVerdict
Integrate & fire
Neuron.integrate/decide		 Weighted sum of inputs + bias, compared to a fixed threshold → 1 or 0. All-or-nothing. Same SHAPE: dendrites sum, soma threshold, spike or rest. ✓ SIMPLIFIED
Faithful in form, but stateless — no membrane potential, no leak, no temporal summation between accounts. A biological neuron integrates over TIME.
Dendritic preprocessing
dendrite.py		 Distributed nonlinear branch combining (soma sees branch activations, not raw synapses). But csm_brain.py never imports or calls it — the brain feeds raw booleans straight to the weights. Dendrites do local nonlinear integration (NMDA/Ca spikes) before the soma. NOT WIRED
The brain's "dendrites" are plain weighted sums; the real dendritic preprocessing module exists and is proven but is not in this runtime.
Action potential / spike None. "Fire" is the integer 1. No voltage, no refractory period, no spike timing, no rate code. All-or-nothing voltage spike, refractory period, timing-dependent (STDP). MISSING
The cell is a perceptron-style decision, not a spiking neuron. No temporal dynamics at all.
Inhibition / veto
amygdala		 Brain uses inhibited = not human_approved — a raw boolean flag. It does NOT use inhibitory.py / arbiter. Inhibition is graded + fast: a conductance with timing and reversal potential, can reduce output a little or a lot. BINARY, machinery unused
inhibitory.py itself declares the veto is ALL-OR-NOTHING (P41-E). And the brain doesn't even call it — it's an if-flag.
Lateral inhibition
Population.step		 Recurrent inhibition across N cells, one settles to one winner. Used for cerebellum + basal ganglia. Lateral inhibition + winner-take-all is the canonical cortical microcircuit. ✓ SIMPLIFIED
Settling is a fixed iters=5 loop, not continuous time — declared scaffolding (no clock).
Plasticity
Neuron.train		 Supervised delta rule from labeled (x,y) examples. Exists, but not called in the brain run — brain uses fixed hand-set weights. LTP is activity-dependent (fire-together-wire-together), mostly unsupervised, timing-dependent. NOT WIRED + simplified
Axon / myelin Drawn in the diagram; in code it's just the output line. No conduction velocity, no saltatory propagation, no delay. Myelin speeds conduction ~50×; timing of arrival matters. LABEL ONLY
Synapse / neurotransmitter Weighted input. No vesicle release, no receptor, no receptor-type distinction (excitatory vs inhibitory is only a sign on the weight). Neurotransmitter release, receptor kinetics, graded postsynaptic potential. MISSING
Hippocampus memory A Python dict keyed by account_id. No consolidation, no replay, no reconsolidation-on-recall. Hippocampus → neocortex consolidation; replay; reconsolidation updates on recall. SIMPLIFIED
reconsolidation.py is proven elsewhere, not here.

4 · Top fixes to make it "act like a neuron"

  • Make the neuron stateful (RED→GREEN-ish). Add membrane-potential integration with leak + refractory period so it integrates over time, not per-call. This is the single biggest biology gap: today the cell has no memory between inputs.
  • Replace the boolean amygdala veto with the graded arbiter. Wire inhibitory.py / runtime.arbiter into the write path and give inhibition strength + timing (P41-E admits it's all-or-nothing today).
  • Wire dendrite.py preprocessing into the sensory path. The brain currently bypasses the one module that makes "dendrites" mean something biological.
  • Either wire the 15 proven parts or stop the hero cell claiming "all 20 in one cell." Recommend: relabel the hero as "Proven parts catalog (portfolio)" and add a second panel "What this brain actually runs" so the picture stops overstating the build.
  • Honest settling. Keep iters=5 but render it as "approximation of continuous-time settling (no clock)" — the code already says this; the visual should too.

Faithful-as-built items to protect: the nervous-system REGION ORGANIZATION (§1), the integrate-then-threshold SHAPE, the lateral-inhibition winner-take-all, and the human-gated write (wired as a veto, never bypassed). Those are the real wins and should not be weakened in the name of more biology.
